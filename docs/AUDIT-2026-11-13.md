# 1.1.1 全量代码审查与安全复核

日期：2026-11-13。对象：当前仓库全部运行时代码、测试、构建/CI 配置及公开文档。方式：代码走查、公开权威资料核对、针对性回归、真实回环 HTTP 测试、部分浏览器操作及安装包校验。**这是开发过程中的自审，不是独立第三方渗透测试、临床验证或“无漏洞”证明。**

## 结论与发布状态

- 修复发现的导航状态、未保存表单、后台刷新版本、歧义输入、备份完整性、演示隔离及模型异常处理问题。
- **152 个不同的自动化测试通过：115 个 Python + 37 个 Node 测试。** Python 在 3.9.6 与 3.12.14 各执行一次，不重复计算测试总数。Node 为 25.6.0。
- 本机记录、原件、分类、餐单、AI 草稿和实际饮食在服务器重启后保持；Key 只在内存，重启后为空。该结论有实际 HTTP 生命周期测试支持，不是只检查字符串。
- 已补齐 README、MIT 版权/打包元数据、详细医疗免责声明、隐私说明、贡献指南、Issue/PR 隐私提示和发布清单。
- **保留开发预览状态。** 最终页内离开确认的独立浏览器端到端复验仍需完成；本次内嵌浏览器自动化遇到原生确认框阻塞，不能把剩余浏览器链路写成通过。详见下文。
- 不保证不存在其他 Bug。没有启用加密、应用登录、多人隔离或公网服务能力，也没有验证真实模型的医学正确性。

## 主要发现与修复

| 问题 | 风险与修复 | 验证方式 |
| --- | --- | --- |
| 后台刷新更新全局档案版本，但页面仍是旧表单 | 旧输入可能冒用新版本覆盖其他窗口更改；提交绑定表单自身 `data-version` | Node 表单提交测试 + Python 409 冲突测试 |
| 异步刷新乱序、整页重绘丢输入 | 增加请求序号；脏表单/保存中不重绘，完成分析不跳离其他页面 | Node 乱序响应、后台云完成与脏设置测试 |
| 子页面只在内存，没有 URL 状态 | 助理任务/历史、护理页签、科室详情编码到白名单 Hash 参数；自定义科室以本地记录 ID 定位 | Node 路由、未知/已删除目标；浏览器科室/症状刷新前进返回 |
| 切页、Escape 和取消没有未保存保护 | 独立页内确认，保留原表单；保存中拒绝跳转；关闭浏览器保留标准 beforeunload 提醒 | Node 继续/放弃、返回、Escape、保存中用例；最终页内对话框浏览器复验待完成 |
| 提交时只锁按钮、准备内容与表单字段可能错位 | 先捕获 FormData，再锁控件；发送预览沿用同一份快照；过期预览不在其他页弹出 | Node 二次提交和预览字段完整性测试 |
| 默认称呼档案已含私有字段或 AI 草稿仍能注入演示 | 初始化检查完整默认档案及所有数据集合 | Python 合成默认称呼/已有草稿拒绝测试 |
| 重复请求头/JSON 键、无效 Unicode、非 ASCII Token | 拒绝歧义输入，避免解析差异或无意义 500 | 真实 HTTP 畸形输入、原始重复头及零写入检查 |
| HTTP 持久连接可能保留未消费请求体 | 每次应用响应关闭连接，避免下一次请求被剩余字节混淆 | 响应头测试与输入走查 |
| 文件损坏/大小元数据不符、迁移读取无界 | 附件只读取上限加一，核对大小及 SHA-256，迁移使用同样读取上限 | 完整性、缺失/去重/备份及大小不符回归 |
| v2 备份遗漏新增集合可被当作空资料 | 必须存在 analyses、routing、routing_version；v1 才采用兼容缺省 | 删除必填字段、重复 JSON 键、旧备份兼容/回滚测试 |
| 未来计划可标记实际已吃 | 服务端拒绝未来实际饮食，计划功能继续可用 | 未来计划和实际饮食 HTTP 测试 |
| 模型畸形响应、重复科室、端点控制符 | 受控错误且不写正式记录；拒绝控制字符和歧义输出 | 模拟 HTTPS/Ollama 畸形响应、端点、重复字段测试 |
| Python 接受而浏览器不认的时间格式 | 限定标准带时区 ISO，Zulu 统一成 `+00:00`；上传日期按本地时区展示 | Python 时间测试 + Node 本地日历测试 |
| 日志类别露出内部英文命名、图表大量参数展开 | 中文映射补齐；极值归约不使用大数组参数展开 | 走查、既有数值及图表测试 |
| MIT 缺少版权行、法律/隐私说明不够细 | 补版权与分发说明，独立 DISCLAIMER/PRIVACY；说明不可排除的法定权利，不声称全面免责 | 文档对照、包许可/资源校验 |

## 浏览器观察与未通过门禁

在隔离的 `127.0.0.1:8767` 合成夹具观察十一项导航、科室目录、设置等页面。自定义“个人记录”详情使用不含科名的本地 UUID 路由，浏览器刷新、返回与前进均恢复相应视图；“症状日记”刷新后 `aria-selected=true` 且 URL 保留 `tab=symptom`。

快速遍历时曾读到 URL 已变化而 DOM 尚未处理 Hash 事件的中间状态，后续针对详情与症状页改用等待具体可见元素，不能把中间读取当作完整 E2E 结果。

本次新增的原生 `window.confirm` 在内嵌浏览器中导致输入命令超时，接口无法取得可操作原生对话框。已删除应用内导航使用的 `window.confirm`，改为保留编辑内容的独立页内 `leave-modal`。之后新页面可以读到最新资源和表单，但该浏览器会话的输入命令仍无法可靠完成点击。因此：

- 自动回归验证页内确认的接受/取消、版本保护、晚到请求和持久化；**不将最终页内弹窗的真实浏览器链路计作通过**。
- 尚需在新的独立现代浏览器会话完成：继续编辑/放弃、嵌套编辑框 Escape、云请求过程中切到设置编辑、保存后刷新、多窗口并发以及窄屏确认框。
- v1.1.0 的桌面/手机和模型模拟流程截图仍是历史证据，不替代这次变更后的复验。
- 浏览器阻塞不影响本机数据测试，不应为修复 UI 删除资料目录。发布者按 [RELEASING.md](RELEASING.md) 完成剩余门禁后再决定公开范围。

## 仍然存在的限制

1. 没有全库/附件加密、应用密码、身份认证、跨用户隔离、多租户和公网拒绝服务防护。
2. 本机恶意程序、管理员、浏览器扩展、交换空间、系统备份及已授权云端留存不在防护保证内。
3. 文件签名/哈希不是反病毒、患者身份核验或不可伪造签名；删除不是安全擦除。
4. 没有临床/营养专业验证、真实视觉识别准确率、过敏安全认证或法规合规认证。
5. 大量数据仍全量加载到页面；没有长时稳定性、恶意高并发、断电/磁盘满全覆盖或全部平台实测。便携 ZIP 有明确大小上限。
6. 外部模型兼容性/费用/留存随服务商变更；未进行真实付费 API 验收。
7. 关闭浏览器的未保存提醒由浏览器决定；尚未保存的文本不自动持久化。最终浏览器交互门禁尚未全部完成。
8. 公共发布前仍须由所有者确认仓库、可见性、版权/第三方权利、私有报告渠道和实际 CI；本次没有提交或推送 GitHub。
