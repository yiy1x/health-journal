# 1.4.0 Apple 健康导入与全量回归验收

日期：2026-11-22。源码 1.4.0，桌面数据库 schema v3；含设备数据的 ZIP 备份 v3，无设备数据时仍 v2。手机静态应用保持 1.2.1。全部测试使用合成资料或新建空白库，未读取用户 Apple/Watch 数据、Apple ID、iCloud 或原有个人档案。

## 1. 结论和完成范围

**312 个不同自动化测试通过：206 Python + 106 Node。** 两种 Python 分别完整执行同一套件，不重复计数。新增 39 个 Apple 解析/统计/事务/备份测试、3 个 HTTP 集成测试、11 个前端模块测试；合计比 1.3.1 增加 53 个不同测试。

交付的是可运行的官方 ZIP/XML 文件导入闭环：上传 → 后台解析/预览 → 范围确认 → 去重保存 → 来源筛选/日趋势/原值明细 → 实际饮食同日回顾 → 静态 TXT 导出/完整备份/批次管理。

**没有交付原生 HealthKit 实时读取或后台同步。** 本机只有 Command Line Tools，没有完整 Xcode，未获真实 iPhone HealthKit 授权/签名配置。没有把 Swift 示意代码或“Apple ID 登录”伪装成真实集成。支持类型及非支持数据见 [APPLE_HEALTH.md](APPLE_HEALTH.md)。

### 新覆盖的边界

- Apple 内部 ELEMENT/ATTLIST DTD、中文主 XML 名称、CDA/GPS 非主内容忽略。
- ZIP 路径穿越/符号链接、无主 XML/多个主 XML、截断内容、XML 实体/外部 DTD/深度/属性/展开限额。
- 18 类类型的代表性输入；lb/km/mi/kJ/s/L 等转换，百分比小数语义，原值和原单位保留。
- 非有限/负值、无时区、非法偏移、未来/倒置日期、跨午夜、夏令时时长；结束日选择不错误套用电脑时区的未来日限制。
- 消除设备描述内存地址造成的重复身份；手工标记保留；不同来源不自动相加。
- 真实零、缺失、来源冲突分开；累计区间重叠不算总量；心率样本均值、末次体重、睡眠并集且排除清醒/在床。
- 预览不写正式库、显式确认、一次性提交、过期/取消/关闭、并发导入拒绝、失败无部分写入。
- 同文件范围幂等、跨文件样本去重、批次共同引用、删除仅移除无引用样本。
- schema v2 升级保留资料、进程重开、样本分页、日期范围限制。
- 备份 v3 全类型往返、样本身份/数值/原单位篡改、批次范围/引用缺失、尺寸保护及占用库恢复拒绝。
- 设备数据不隐含进入 AI `include_records` 或原件互传；已有设备数据不能混入 demo。
- 仅人工实际饮食进入回顾，未吃计划和未核对 AI foods 不混入事实。
- SVG 图表不用违反 CSP 的内联样式、不把缺口连线；文本/来源/原件名转义，表单防重复提交、失败保留输入、轮询不持续泄漏、切页后不继续安排解析轮询。

## 3. 规模测试

独立临时库，**100000 条不同的合成心率样本**，每分钟一条，约 70 日；XML 22900025 字节。不是用大量重复条目冒充同样数量的唯一记录。

| 步骤 | 本机测得 |
| --- | --- |
| 解析并暂存 | 2.694 秒 |
| 确认并事务保存 | 0.571 秒 |
| 查询 91 日日值 | 0.272 秒 |
| 保存/查询计数 | 100000，日样本计数总和一致 |
| 缺失日期 | 21 日，保持缺失而不是零 |
| 临时原文件 | 解析后已清理 |

另执行过 100000 项/3600 唯一样本的重复压力场景，确认文件内重复计数。以上不是跨设备性能承诺，也没有声称实测了 1 GiB 或 100 万条最高限额。页面按日传输聚合结果，不传整份样本库；大量区间统计仍需要排序和一定内存。

3. 选合成手表后结束日为 6690 步、有效 14/28 日；不是 28 日全覆盖。
4. 切到心率后结束日为 65 次/分，有记录日日值均值为 66.21，并有算术均值口径说明。

6. 未加密 TXT 导出先确认，再生成独立“保存回顾 TXT”链接；实际下载成功，不只依赖 toast。
7. 刷新后样本数保留；错误日志为空。
8. **12 页 × 320/390/768/1280 宽度，共 48 个布局检查**，未发现页面级横向溢出；长表格留在自身滚动容器。

## 5. 发现并修复的问题

- Python 3.9 不接受 Apple 常见的紧凑 `+0800` ISO 解析形式：显式标准化为 `+08:00`，保留原时区语义；另拒绝时区分钟越界。
- 设备描述可能含进程内存地址，重新导出会改变：身份计算去除此易变地址，版本信息单独保留。
- 图表内联 style 会被现有严格 CSP 阻止：改为本地 SVG 数值属性与 CSS class。
- 轮询进入页面时可能在每次 render 再次启动：增加页面进入状态，完成后不持续重复轮询。
- 从完整日样本列表聚合可能占用大量内存：查询逐日迭代、均值流式计算，只为区间并集保留必要区间。
- 只留标准化值会丢失转换依据：保存原始值/单位，并在备份恢复重算验证。
- 电脑时区与样本时区不同，合法“结束日”可能比电脑今天多一天：不把范围选择当作本机未来事件，原始样本仍按绝对时刻拒绝未来数据。
