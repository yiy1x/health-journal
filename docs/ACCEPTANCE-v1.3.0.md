## 本次发现和修复

- 授权弹窗冻结连接类型和任务，避免切换到其他连接后发送旧预览。
- 控制/配置与分析互斥；被拒绝的重复登录或忙状态操作不会错误终止正常连接。
- 账号刷新采用代次检查，不把旧账号/模型标记为新会话；取消/停服后不保存未完成结果。
- 登录 URL 两端限制官方 HTTPS 来源；不展示原始上游错误；畸形协议关闭连接而不是继续猜测。
- 子进程写队列有界，安全配置按类型和值严格检查；相对 PATH 查找结果转为绝对路径后启动。
- **图片回显与输出限额区分**：Codex 的 userMessage 会回显输入；允许 13 MiB 输入回显后立即移除冗余内容，一般输出仍限 2 MiB。仅排队所需生命周期事件，队列 32 项，防止流式片段累积。
- 模型连接页可以在页面刷新后取消服务器仍在运行的操作；取消不删除此前已保存的草稿。
