## 自动测试覆盖的关键风险

- 六类记录校验、异常类型、空值、非法日期、非有限数字、参考上下限关系、症状整数程度、处方来源及起止日期。
- 报告诊断必须关联真实存在的本地原件；自述/怀疑不会自动升级为诊断。
- CRUD 持久化、记录版本冲突、同时更新只允许一次成功、档案设置冲突、原件仍被引用时拒绝删除。
- 文件签名、UTF-8、NUL、文件名路径字符、空文件及大小限制；重复内容识别、损坏附件拒绝下载/导出/静默去重。
- 便携备份恢复保持记录 ID、版本、时间、文件、档案和餐单；演示标记保留，模型配置不带入。
- 拒绝非空库恢复、路径穿越、未知 ZIP 条目、损坏哈希、重复 ID、丢失引用、错误版本/时间戳、错误餐单、超大解压量；模拟写入失败回滚。
- API 的 Host/Origin/Fetch Metadata/令牌、静态路径白名单、请求大小、重复 Content-Length、JSON 对象约束、NaN/Infinity 拒绝。
- 一般餐单可重复生成且遵守已标注过敏/蛋奶素规则；未知过敏、未成年、特殊饮食需求等保守暂停。
- 已有实际饮食记录不可整日覆盖或替换；限制变化后仍可记录历史事实，但不能继续推荐不适用餐单。
- 用药按状态和日期判断；指标待核对/非精确值不会误标为正常；缺资料不作无病保证；超过 12 条摘录会明确说明不完整。
- 模型启用必须为明确布尔值；已知云模型、远端元数据及重定向被拒绝；持续危险表现不等待模型；模型草稿与正式记录分离。
- 前端内容转义、小数不粗暴舍入到零、趋势分组/过滤、同日相同数值及超大量级保护、空档案九个页面、完整摘要字段。

## 真实浏览器验收

在 Codex 内置浏览器操作了运行中的本地应用，而不只是检查代码。

| 流程 | 实际观察 |
| --- | --- |
| 九个页面导航 | 总览、时间线、原件、趋势、用药症状、饮食、助理、摘要、设置均可打开 |
| 新建记录 → 搜索 → 编辑 → 再打开 | 合成记录正确出现；编辑后的备注保留，版本号变为 2 |
| 原始 TXT 查看 → 摘录 | 内容与合成原件一致；摘录表单自动选中对应原件，未自动标为已核对 |
| 指标趋势 | 展示 5 次合成 LDL 记录，单位/机构/原参考范围与来源列表一致 |
| 用药/症状/健康问题 | 无药时显示未记录；症状为自述；原因待查明确不是确诊 |
| 实际饮食记录 → 重新安排 | 已吃标记与备注保存；重新生成被拒绝，原记录不丢失 |
| 档案助理 | 检验问题引用 5 条本地来源，给出原数值和参考范围提醒；未执行模型推断 |
| 就医摘要 | 核对了诱因、来源、原件名、报告参考范围、就诊主诉/医生/原文摘录/备注、特殊饮食区块 |
| 设置保存 → 刷新 | 合成联系人字段正确持久化，没有填入真实联系人 |
| 窄屏九页 | 请求视口 390×844；浏览器实际报告 354 CSS px；每页文档宽度均为 354，无整页横向溢出 |
| 桌面九页 | 请求视口 1280×900；浏览器实际报告 1163 CSS px；每页文档宽度均为 1163，无整页横向溢出 |
| 控制台 | 最后一轮读取到的 error/warn 列表为空 |

已还原临时视口设置，保留应用浏览器标签供直接体验。可查看 [首页实际视口截图](screenshots/overview.jpg)。截图和本地演示库中包含验收新增的合成记录，不是真实个人资料。

## 明确没有验证或没有实现的事项

- 未连接真实医院系统、医疗设备或真实患者档案。
- Ollama 调用、云模型拒绝及草稿边界通过模拟响应测试；本机未安装真实模型进行推理质量评测。
- 没有声称完成 OCR、疾病诊断/预测、处方生成、营养充分性验证、全库加密、后台通知或多设备同步。
- 就医摘要页面内容和打印样式已检查；没有进行物理打印或逐页核验操作系统生成的 PDF。
- Windows/Linux 由 CI 配置准备覆盖，但本地没有真实运行这些系统；GitHub Actions 尚未在远端执行。
- 未进行医学专家审查、外部安全审计、长期稳定性/海量数据压力测试或断电故障注入。
