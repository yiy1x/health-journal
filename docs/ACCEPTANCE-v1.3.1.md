# 1.3.1 空白初版验收

日期：2026-11-16。目标：从无个人资料的初始状态开始使用，而不是隐藏演示标记后继续显示虚构病历。

## 清理范围

- 全量搜索桌面/手机页面、初始化入口、演示生成器、文档、测试中的演示文字和预填内容。
- 移除首页“独立的合成演示档案……不带 --demo”的开发提示及专用样式。普通启动不会进入演示库，也不会出现演示标签或虚构摘要。
- 新档案的称呼、生日、联系人、备注、饮食医嘱均为空；性别和饮食偏好为未填写；没有已勾选的过敏原或膳食适用确认。
- 就诊、指标、用药、症状、健康问题、随访、附件、餐单、分析草稿、实际饮食全部为空，统计为 0。不设置模型、Key、Codex 登录或连接。
- 未填写称呼时，首页标题为“我的健康档案”，摘要为“就医摘要”，不把占位名称写进数据库。零指标空态不再说“再记录一次”。
- 未选择饮食偏好时禁止生成餐单，不把未填写解释为“均衡搭配”。
- README 快速启动和安装示例改为普通启动，主截图改为空白初版。

保留 55 科目录、过敏选项、菜谱规则和输入示例占位符：这些是功能定义，不是个人资料。保留医学、隐私、外发确认提示。历史验收记录、自动化合成夹具、显式 `--demo` 的来源标记和演示备份标记不删除，以免虚构资料被误认为真实记录。

## 数据保护

当前 8769 地址改用新目录 `.local-personal-v1`；原 `.local-codex-v1.3-demo` 完整保留，没有清表、删除文件、复制登录凭证或改成“真实档案”。其他服务和手机浏览器资料不改动。

再次启动同一个个人目录会继续使用已保存的资料，不会每次清空。其他人的新安装使用 README 中的默认仓库外目录；不要把真实资料提交 GitHub。
