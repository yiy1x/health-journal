# 用 ChatGPT 账号连接 Codex

适用：桌面 1.3.0，2026-11-16。可选开发预览；不是通用第三方 ChatGPT OAuth，也不是把订阅转换成 API Key。

## 安装与使用

本应用启动你安装的**官方 Codex CLI**，通过官方 App Server 标准输入/输出协议控制独立连接。CLI 自己管理 ChatGPT 登录，本应用不接收密码、验证码或手工粘贴的令牌。用户授权后，CLI 使用账号的 Codex 权益请求模型。可用套餐、地区、工作区政策、模型、额度、费用以官方实际返回为准，不能承诺任何账号都能使用或无限免费。

1. 从 [官方 CLI 安装说明](https://developers.openai.com/codex/cli/) 安装 Codex，检查 `codex --version`。
2. 正常启动健康手记。默认从 `PATH` 找 `codex`；找不到时指定官方可执行文件绝对路径：

   ```bash
   python3 -m health_journal --codex-bin /absolute/path/to/codex
   ```

   桌面客户端内置 CLI 的路径可能变化，优先使用独立官方安装，不硬编码别人的路径。
3. 在“模型连接”点击“连接本机 Codex”，再点击“使用 ChatGPT 登录”。此时不分析医疗资料，但 Codex 可能联网加载账号/模型元数据。
4. 点击 **OpenAI 官方登录页**，亲自完成登录，返回点击“登录后刷新状态”。如显示“登录状态刚刚变化”，再刷新一次。
5. 选择账号返回的模型并保存。需要图片时勾选图像能力，仅接受 CLI 明确报告支持的模型。
6. 点击“使用此连接分析”，或在“档案助理”选择“ChatGPT 账号 · Codex”。先用合成短文字试用，再考虑真实资料；逐次阅读并确认外发预览。

支持餐食识别、报告文字整理、健康资料问答草稿；文字及一份 JPG/PNG（8 MB），TXT 原件最多 60000 字符。**不直接发送 PDF**，请选必要页面图片或文字摘录。手机独立资料版暂不提供登录或模型调用，不能把电脑端口开放到局域网来替代手机实现。

## 设计与安全边界

```text
本地页面 → 回环 HTTP（会话令牌 + Origin/Host 校验）
         → 冻结并预览授权 → 确认后 Codex stdio 子进程
         → OpenAI Codex → 校验 JSON 草稿 → 本地 SQLite
```

- 不启动 Codex WebSocket 服务，不开放远程 RPC、任意命令、LAN 端口。官方登录自身可能使用本地 OAuth 回调端口，它不是健康档案服务。
- `<资料目录>/.codex-connection/auth` 是独立 `CODEX_HOME`；每次建立连接创建临时 HOME/USERPROFILE 和空工作目录。不读取原有 `~/.codex` 登录、插件、配置、历史或项目指令。
- 环境白名单不继承 API Key、Codex Token、代理及 Node 启动注入变量。代理、企业网关和定制证书环境不保证可用，不得为连通而关闭安全校验。
- 强制内置 OpenAI provider、ChatGPT 登录、只读沙箱、禁止审批；禁用 shell、联网搜索、浏览器/电脑操作、MCP、插件、钩子、技能、记忆和多代理等。启动时 `config/read` 逐项验证有效配置；不匹配拒绝连接，不降级。
- 临时线程；检查返回模型/provider/沙箱/审批策略；回合只允许读取空工作目录。工具请求或工具事件会使连接失败，应用不自动批准。
- JSONL 收发有长度和队列边界，拒绝重复键、不兼容响应及服务端主动 RPC 请求；错误不显示原始协议、Token 或上游报错；stderr 丢弃。
- 10 分钟一次性授权，最多 8 份待确认，Codex 连接一次只分析一个请求。模型/连接/账号变化使旧授权失效；切换页面连接不会把旧授权发给另一服务商。
- 草稿通过本地结构、长度及科室校验才保存，不执行模型输出，不自动新增诊断、改药、确认科室。**结构正确不等于医学正确。**

## 凭证与隐私

选择 Codex 文件型凭证存储，持久化在隔离目录，**可能包含可用的明文访问/刷新令牌**。应用不读取解析这些令牌，不返回浏览器、不存进 SQLite、便携 ZIP 或手机互传。POSIX 目录权限 0700；Windows ACL 需自己检查。

**复制整个资料目录会连同凭证一起复制。** 启用磁盘加密，不放 Git、公共网盘或共享目录；`.gitignore` 不是防泄露保证。本应用不保存协议日志，但 Codex/系统仍可能保存诊断、缓存、元数据或崩溃/交换副本。临时线程不保证全程无明文残留。正常断开清理临时目录，崩溃断电不保证清理完成。

“断开”只停止子进程，**不等于退出账号**；移除登录需先连接再“退出此连接的账号”。退出不等于安全擦除或吊销所有远端会话。怀疑凭证泄露请使用官方账号安全控制，切勿把 Token 发给维护者。

ChatGPT/Codex 数据政策和训练选项取决于账号及工作区，**不能套用 API 默认政策或 `store:false`**。应用不控制 OpenAI 留存，也不能撤回已发内容；见 [官方认证说明](https://developers.openai.com/codex/auth/) 和账户隐私设置。

## 故障恢复

| 情况 | 行为和建议 |
| --- | --- |
| 找不到 CLI / 不兼容 | 未发送健康资料；核对官方安装/版本，不切换全权限模式 |
| 登录取消、未完成或刚变化 | 不允许旧授权分析；刷新或重新登录，再预览 |
| 图片能力不支持 / PDF | 本地准备阶段拒绝，不静默截断或转码 |
| 额度、网络、协议、草稿错误 | 不自动重试；检查已有草稿，重新连接并预览 |
| 取消 | 停止整个连接，不保存尚未提交的本次草稿；已发送内容/额度不能撤回 |
| 取消与保存同时发生 | 以服务端完成顺序为准；已保存则取消返回冲突，不偷偷删除 |
| 刷新或关闭浏览器 | 不自动取消后端分析；模型连接页可取消在途请求，历史可查已保存结果 |
| 停止服务 | 终止子进程，旧授权失效；保留资料及持久凭证 |

单次 RPC 等待通常最多 15 秒；分析事件等待截止时间从建线程前起计 150 秒，RPC/清理/系统调度可能增加少量时间，**不是严格端到端 SLA**。取消不证明上游停止或未计费。应用不自动重试，不代表官方 CLI/上游内部绝无网络重试。

## 兼容与实测范围

本机验证官方 `codex-cli 0.167.0-alpha.3.2` 的匿名启动、完整安全配置校验、未登录账号读取和清理。其他版本可能拒绝连接，不因版本更高绕过安全检查。真实官方 CLI 只在本机 macOS 验证；Windows/Linux 的沙箱兼容性未验证。Windows 仅停止直接子进程，不保证清理第三方 CLI 的所有孙进程。

分析、图像编码、授权、超时、取消、HTTP/UI 全流程用**独立离线模拟进程与合成数据**测试。没有读取既有账号、登录真实账号或消耗额度；真实登录/模型端到端、医学质量和物理手机仍需独立验收。见 [验收报告](ACCEPTANCE-v1.3.0.md)。

## 官方依据（2026-11-16 核对）

- [App Server](https://developers.openai.com/codex/app-server/)：stdio JSONL、初始化、账号、模型、线程、回合。
- [Authentication](https://developers.openai.com/codex/auth/)：ChatGPT 和 API Key 区别、凭证管理。
- [Configuration reference](https://developers.openai.com/codex/config-reference/)：安全配置和功能限制。

未使用内部不稳定的 `chatgptAuthTokens`，未抓取 Cookie、复制原有认证文件、伪装通用 ChatGPT 登录或把订阅代理给其他人。
